Portfólio — Michelle Siqueira Mendes
Este projeto foi desenvolvido como parte dos meus estudos em Desenvolvimento Front-end no Programa Trilhas.
O site apresenta um pouco sobre mim, meus estudos e meus primeiros passos na programação. Utilizei HTML para estruturar as páginas e CSS para trabalhar o visual, as cores e a organização dos conteúdos.
Arquivos do projeto
index.html — página inicial do portfólio.
sobre.html — página com informações sobre mim.
projetos.html — página para apresentar meus projetos.
style.css — arquivo responsável pelos estilos do site.
img/ — pasta destinada à foto de perfil.

Sobre o projeto
Escolhi tons de lilás e rosa para a identidade visual. Como estou começando na área, este portfólio também serve para acompanhar meu aprendizado e reunir os trabalhos que desenvolver ao longo do curso.
Pretendo atualizar a página conforme adquirir novos conhecimentos e criar outros projetos.
